## Must fix before Force Eject is used on a real drive
1. **BUG** `EjectFlow.swift:718` S2 fails open: when every `statfs`/`realpath` fails (sick drive, EIO), `uniqueTargets` is empty → scanner returns `incomplete=false`, no holders → no blockers → Force enabled with holders unknown. Fix: in `recomputeGate` add `.scanIncomplete` when `lastScan.scannedTargets.isEmpty` while `disk.volumePaths` is non-empty (or scanner sets `incomplete` for any requested path it cannot resolve).
2. **RISK** `EjectFlow.swift:476` confirmation re-check only tests `blockers.isEmpty`; holders/risks that appeared after the sheet was shown (e.g. NLE mapping media read-only → SIGBUS risk) are force-ejected unseen. Fix: if fresh holder pids or `.mappedFile`/uninspectable risks are not a subset of the confirmation's `holders`/`risks`, refuse with a note and re-show the sheet.
3. **RISK** `InUseAlert.swift:157` Cancel disabled while `.forcing`; if `sync_volume_np(FULLSYNC|WAIT)` or the forced DA request stalls on a sick drive the modal cannot be dismissed. Fix: keep Cancel/Hide enabled during `.forcing` (closes UI, request continues in background, logged) + timeout note.

## Fix before release (RISK)
- `DebugSupport.swift:22` any same-user process can launch a second DriveUser with `--debug-hooks --screens <dir>`, write `press Force Eject` to the cmd file, send SIGUSR1 → Force Eject without a click. Fix: `#if DEBUG` around `--eject`, `--debug-hooks`, SIGUSR1 source (L142-203). (Phase 5 brief also gates them behind `DRIVEUSER_DEBUG=1`; do both.)
- `EjectCoordinator.swift:72` `.failed` event lacks the approval kind (`EjectWatcher.swift:39`). A foreign single-volume unmount (Disk Utility "Unmount", `diskutil unmount`, backupd unmounting a TM destination) becomes an automatic whole-disk eject once holders clear (`EjectFlow.swift:607`) — beyond what was requested, not covered by S8. Fix: pass kind in event; for `.unmount` attempts retry only that volume's unmount, or require a click before any retry.
- `EjectCoordinator.swift:159` `sessions[key]` checked before the S8 `runModal`; a foreign failure during that modal creates a companion session that `makeSession` (L192) overwrites → orphan flow retrying + companion window never dismissed. Fix: re-check after `confirmMultiVolume`; refuse in `makeSession` if key exists.
- `EjectCoordinator.swift:220` `showError` `runModal`s on top of a running menu InUseAlert; when the menu flow ends, `dismiss()` (`InUseAlert.swift:253`) `stopModal`s the error alert instead → InUseAlert stuck modal with `dismissed=true`, app wedged. Fix: queue plain alerts until no InUseAlert modal runs, or loop `runModalSession` until `dismissed`.
- `InUseAlert.swift:255` companion mode: `dismiss()` only orders out; `runNested` (L329) stops nested modal only when `presentation == .modal` → Force / stop-writer confirmation stays on screen after flow ends (inert but dangling). Fix: if `confirmation != nil`, `NSApp.stopModal` regardless of presentation.
- `InUseAlert.swift:300` confirmation has no default button; with Full Keyboard Access the first key view is "Force Eject" and Space confirms. Fix: `a.window.initialFirstResponder = cancel`.
- `StatusMenuController.swift:98` every menu open / mount event calls `physicalDisk(forVolume:)` per drive on main (creates DA session, walks IOKit, reads resourceValues for every local mount, `DiskTopology.swift:171/219`); `start()` (`EjectCoordinator.swift:142`) statfs's on main. A wedged local volume stalls main. Fix: compute topology in VolumeMonitor's background refresh, cache per volume.
- `EjectFlow.swift:576` `diskChanged`/`notFound` with changed appearance time reported as "Ejected X"; surprise removal / USB re-enumeration during a flow gets a success toast even when the same volume is mounted again from the new disk instance → user may unplug a mounted disk. Fix: report "disconnected"; if a `disk.volumePaths` entry is mounted again say it is still mounted.
- `Holder.swift:121` `parentRunningApplication` returns first app with the parent bundle URL; with `open -n` instances Force Quit on a helper row can `forceTerminate` the wrong instance. Fix: prefer the app whose pid is `h.ppid`; several candidates and none match → nil.
- `HolderResolver.swift:56` (+question) any same-user process with an NSRunningApplication is `.app`/`.appExtension` → quittable/force-quittable; no never-quit list for session processes. Fix: `neverTerminate` for `com.apple.loginwindow`, `com.apple.dock`, `com.apple.systemuiserver`, `com.apple.controlcenter`, `com.apple.WindowManager`, `com.apple.notificationcenterui` (and Finder's Force Quit → relaunch semantics only).
- `HolderScanner.swift:288` non-bundled processes still rely on the PATHINFO3 probe; getattr failure on an earlier mapping (offline SMB) reads as "no mmap" silently, no `incomplete` → CLI with MAP_SHARED writable mapping missed, Force goes through. Fix: when any network mount exists use the region walk for all processes, or mark incomplete on probe EINVAL when the process has vnode regions.
- `HolderScanner.swift:353` PATHINFO2 walk `break`s on first failure; kernel also returns EINVAL when `vnode_getwithvid` fails (vnode being reclaimed) → later regions never checked, silent. Fix: on failure step past the region with `PROC_PIDREGIONINFO`, continue, set `truncated` → incomplete.
- `Tests/EjectKitTests/EjectFlowTests.swift:300` `XCTAssertTrue(disk.isVirtual)` doesn't stop the test; the live flow that follows uses `.externalDisks` → a non-image disk at that path would be soft-ejected. Fix: `try XCTSkipUnless(disk.isVirtual)`.
- `Tests/EjectKitTests/ScanTests.swift:125` bundled region-walk test stays green if the fallback branch (`HolderScanner.swift:275`) is deleted. Fix: call `mappedFiles(pid:targets:only:nil,from:0)` directly and compare to the probe, or inject a probe failure.

## NIT
- `EjectFlow.swift:452` `confirmForceEject` ignores `ejectInFlight`; forced request can run alongside a pending soft one (benign, noisy). Fix: refuse/defer while in flight.
- `EjectFlow.swift:559` dissenter pid not filtered against `getpid()`; if DriveUser itself is the dissenter it becomes an `.app` row and Quit All would terminate DriveUser. Fix: drop + log.
- `EjectFlow.swift:810` `remedyApp` prefix match: `com.apple.music` matches `com.apple.MusicRecognitionMac`; Resolve prefix matches Project Server. Fix: exact first, prefix only when it ends with "." or matches the label.
- `HolderScanner.swift:103` test-only `inspectHook` compiled into release (unreachable without `@testable`, one lock per pid). Fix: `#if DEBUG`.
- `LibProc.swift:113` no test for COPY-inherited writable mapping that is not COW (MAP_SHARED + `minherit(VM_INHERIT_COPY)`); removing the SM_COW confirmation keeps the suite green. Fix: add a duhold mode.
- `Terminator.swift:81` S4 Quick Look exception matches executable basename only; a same-user `.daemon` named QuickLookSatellite under /Library gets SIGTERM/SIGKILL. Fix: also require `executablePath.hasPrefix("/System/")`.
- `AppDelegate.swift:5` no `applicationShouldTerminate`; quitting mid-flow abandons in-flight results unlogged (S9), incl. a forced request in its flush. Fix: log open flows + states on terminate.
- `build.sh:16` no bloat; `__text` 460 KB of 804 KB; `__LINKEDIT` 196 KB from exported EjectKit symbols. Optional: `-Xlinker -no_exported_symbols` + full `strip` saves ~150 KB.
